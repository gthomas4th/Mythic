# ADR-001 — Mythic foundation

Accepted by the supplied architect handoff. Retain Mythic's existing runtime,
Epic/Legendary integration, GPL-3.0 license and upstream remote. Add Steam through
provider-neutral records and a temporary legacy adapter. No rebrand or runtime rewrite.

The first slice is an in-memory overlay; permanent catalog database selection remains
in Phase 2. This document does not choose between SwiftData and SQLite.
